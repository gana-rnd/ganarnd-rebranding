## Citation limits — how these may be described
## 인용 제한 — 표기 방법

| Do not write | Write instead |
|---|---|
| "Registered in our name" (Russia) | **"Named as manufacturer"** — registration holders are local representatives |
| "FDA approved" · "FDA registered" | Nothing — no US device registration exists |
| "Russia FDA" · "KFDA" | **Roszdravnadzor** · **MFDS** |
| CE mark / ISO badges | Nothing until renewed and located |
| The UK Class III device brand | **"Manufacturer registered with MHRA (MAN_ID 32678)"** — the device brand belongs to the market-authorisation holder and cannot be named until the manufacturing contract is reviewed |
| "38 registrations" | **"36 active registrations across five jurisdictions"** |

| 쓰지 않을 것 | 대신 쓸 것 |
|---|---|
| "우리 이름으로 등록" (러시아) | **"제조자로 기재"** — 등록 명의인은 현지 대리인 |
| "FDA approved" · "FDA registered" | 사용하지 않음 — 미국 의료기기 등록 없음 |
| "Russia FDA" · "KFDA" | **Roszdravnadzor** · **MFDS** |
| CE 마크 · ISO 배지 | 갱신·원본 확인 전까지 사용하지 않음 |
| 영국 Class III 기기 브랜드명 | **"MHRA 제조자 등재(MAN_ID 32678)"** — 기기 브랜드는 시판허가자 소유이며 위탁생산 계약 검토 전까지 명시 불가 |
| "38건 등재" | **"5개 관할 36건 유효 등재"** |
