- **작성 기준일**: 2026-07-22
- **성격**: 브레인스토밍 결과 고정본. 채널별 세부 요건(마감·비용·심사 기준)은 **미확인** — 기획서 반영 전 실사 필요.
- **베이스**: [브랜드 아키텍처 재생 사다리](archive/04_브랜드아키텍처_재생사다리_2026-07-22.md) · [통합보고서 v2.1](GANA_그룹_리브랜딩_통합보고서_v2.md) · [World Largest 포지셔닝 분석](GANA_world-largest_포지셔닝_분석.md)
- **전제**: 회장님의 목표가 **매각·수익이 아니라 인정·가시성**이라는 가설([아키텍처 §2](archive/04_브랜드아키텍처_재생사다리_2026-07-22.md)). 이 가설이 뒤집히면 본 문서의 우선순위도 재검토 대상.

## 0. 한 장 요약

| 항목 | 결론 |
|---|---|
| **핵심 진단** | 목표가 가시성인데 **현 로드맵에 3자 채널이 하나도 없다.** P0~P5 전부가 자사 사이트 작업 |
| **13년치 대조군** | 자사 채널 13년 = 무반응 / 3자 채널 1건(써모피셔) = 4개 매체 확산 |
| **자사 vs 3자 관계** | 병렬 아님. **직렬** — 3자=발견, 자사=검증. 사이트는 부수적이 아니라 **순서가 나중** |
| **최우선 채널** | **② 레지스트리(바닥·상시)** + **① 파트너 보도자료(스파이크·간헐)** |
| **레지스트리의 본질** | 신규 투자가 아니라 **이미 지불한 등록비의 회수** |
| **숨은 효과** | 규제기관 도메인이 딜러 사이트를 검색에서 압도 → **SEO 문제의 우회 해법** |
| **핵심 논리** | 우리가 "응급처치"라 부른 것들(SSL·도메인 이메일·숫자 일관성)은 **가시성 채널의 입장권** |
| **⚠️ 순서** | **정리 → 노출.** 뒤집으면 가시성이 독이 된다 |

## 1. 전제 — 이 그룹은 이미 대조군을 갖고 있다

| | 기간 | 결과 |
|---|---|---|
| **자사 채널** (ganarnd.co.kr) | 13년 | 자기 제품명으로 검색 미노출. 딜러가 상단 |
| **3자 채널** (Thermo Fisher 보도자료) | 1건 | Business Wire → BioSpace · Technology Networks · medpath 확산 (확인) |

같은 회사, 같은 기간. **우연이 아니라 메커니즘이다.** 그리고 현 로드맵은 아무 일도 일어나지 않은 쪽에 100% 투자하고 있다.

> **부수 관찰**: 지금도 3자 노출은 존재한다 — 다만 **무권한 딜러**(루마니아 Georock 등, 20종 무단 리스팅)가 그 노출을 만들고 있다. 목표는 "3자 노출을 만든다"가 아니라 **"3자 노출의 주체를 바꾼다"**.

> **딜러 프레이밍 교정**: 딜러가 상위 노출되는 것은 도둑질이 아니라 **대가**다. 13년간 수요 발굴을 딜러가 대행했으므로 브랜드 지분도 그들에게 축적됐다. 따라서 정확한 표현은 "브랜드를 되찾자"가 아니라 **"수요 발굴을 우리가 다시 가져오자"** — 회장님·딜러 양쪽에 덜 자극적이면서 사실에 부합.

## 2. 자사 채널과 3자 채널은 직렬이다

```
   [3자 채널]              [자사 채널]
    발견 discovery    →     검증 verification
   레지스트리·보도자료·        사이트·팩트시트·
   학회·리포트               Trust Center
        │                        │
   여기서 처음 만난다        여기서 확인한다
                                 │
                          ⚠️ 보안 경고가 뜨면
                             발견은 0으로 수렴
```

**13년간 사이트가 안 중요했던 진짜 이유는 아무도 도착하지 않았기 때문이다.** 3자 채널을 켜는 순간 사람들이 도착하기 시작한다. → **가시성 전략이야말로 사이트를 중요하게 만드는 요인이다.** 사이트는 중요도가 낮은 게 아니라 **순서가 나중**이다.

## 3. 채널 인벤토리 — 6종

| # | 채널 | 성격 | 비용 | 리드타임 | 통제 가능성 |
|---|---|---|---|---|---|
| **①** | **파트너사 보도자료** | 스파이크 · 간헐 | 거의 0 | 1~3개월 | 낮음(벤더 결정) |
| **②** | **레지스트리 등재** | **바닥 · 상시 · 영구** | **이미 지불** | 즉시~ | 높음 |
| ③ | 학회·컨퍼런스 발표 | 심사 통과 = 3자 검증 | 중 | 3~12개월 | 중 |
| ④ | 산업 리포트·디렉토리 | 시장조사 경로 확보 | 저~중 | 3~6개월 | 중 |
| ⑤ | 업계 미디어 기고 | 전문성 노출 | 저 | 2~4개월 | 중 |
| ⑥ | 논문·특허 | 가장 느리고 가장 오래감 | 중 | 12~24개월 | 낮음 |

**①과 ②는 우열이 아니라 역할 분담이다.** ②가 상시 작동하는 바닥이고, ①이 간헐적으로 도달을 만드는 스파이크다. **②가 먼저** — 보도자료를 보고 찾아온 사람이 확인할 것이 있어야 한다.

> **어워드는 의도적으로 제외.** pay-to-play 비중이 높아 잘못 받으면 신뢰가 깎인다.

| | 1층 피부 재생 | 2층 조직 재생 | 3층 세포·유전자 재생 |

| **청중** | 딜러·클리닉·ODM | 규제기관·의료 유통 | 제약·바이오·투자자·업계 |

| **레지스트리** | **러시아 РЗН 7건 (확인)** · CE(만료) · ANVISA(미확인) | **러시아 РЗН 2024/22431 (확인)** | cGMP·시설 인증·(향후 ClinicalTrials.gov) |
| **미디어** | 딜러·시술 미디어 | 창상관리 저널 | BioProcess International 류 |
| **언어** | 6개국어 | EN | EN(+ZH) |

> **🔴 정정 (2026-07-22 조사 반영)**: 본 문서 초판은 *"KoraVie Shield의 UK MDR Class 2a 등재"*를 2층의 3자 기록 자산으로 인용했다. **오류다.** 규제대행사 공개 문서는 **Class I** skin-barrier device로 서술하고, koravie.info 자체도 *"Class 2a (upgrade in process)"*로 표기한다. **Class 2a는 보유가 아니라 진행 주장이다.**
>
> **2층의 실제 3자 기록은 다른 곳에 있었다** — GANA PATCH가 **러시아 Roszdravnadzor РЗН 2024/22431**로 유효 등재돼 있다(하이드로겔 창상피복재, 2024-04-18). 영국이 아니라 러시아였고, KoraVie가 아니라 GANA R&D 명의였다.

## 5. 등재 요건 역산 — 회장님 설득 논리의 완성

**"3자 채널에 들어가려면 무엇이 필요한가"를 거꾸로 계산하면, 우리가 P0 응급처치라 불렀던 것이 전부 나온다.**

| 필요한 것 | 어디에 쓰이나 | 현재 상태 |
|---|---|---|
| 작동하는 HTTPS | 애널리스트·심사위원이 사이트를 연다 | 🔴 자체서명 → 보안 경고 |
| 도메인 이메일 | **등재 신청서 필수 기입란** | 🔴 개인 네이버 |
| 일관된 시설 스펙 | 리포트 등재·기고·발표 초록 | 🔴 5,000 vs 6,000 / 26 vs 40 |
| 단일 영문 표기 | 검색 통합·인용 정확도 | 🔴 GANA RND vs GANA R&D |
| 대표자 실명·직함 | 발표자 등록·기자 인용 | 🔴 "Dr. Park"만 (외부는 Yong-Ho Park) |
| 레지스트리 번호 | 3자 검증 링크 | 🟡 보유하나 배지 이미지로만 사용 |

**프레이밍 전환**: 지금까지 이것들을 "리스크 관리"로 팔려 했으나, 13년간 리스크가 발현되지 않았으므로 회장님께 안 먹힌다. **"입장권"으로 팔면 먹힌다.**

> *"SSL과 이메일을 고치자는 게 잔소리가 아닙니다. **산업 리포트 등재 신청서에 개인 이메일을 쓰면 반려됩니다.** 학회 초록에 시설 스펙을 두 가지로 쓸 수 없습니다. 이건 청소가 아니라 입장권입니다."*

## 6. 써모피셔 사례 해부 — 재현 가능한가

**성사 경로 (확인)**: 닥터박이 TF를 공급사 선정 → **TF가** 보도자료 발행(Business Wire, 2025-09-24, ID 20250923771397) → 3개 이상 매체 재유통.

**왜 TF가 냈나 (추론)**: AAV 5,000L급 수주는 벤더에게도 자랑거리다. 케이스 스터디 수요가 있었다. 즉 **우리가 부탁해서가 아니라 이해가 맞아서 성사**됐을 가능성이 높다.

**재현 조건 3가지**: ① 벤더에게 자랑거리가 될 규모 ② 고객사 공개 동의 ③ 벤더 마케팅팀 접점

**재현 가능한 트리거 이벤트**: 추가 장비 도입 · cGMP 인증 취득 · Phase 1 준공 · 첫 GMP 배치 출하 · 신규 서비스 런칭

**미활용 자산**: R&D 센터 투어 페이지에 나오는 벤더들 — **Cytiva(AKTA) · Beckman Coulter · Leica · Thermo Fisher** — 전부 고객 스토리 프로그램을 운영하는 규모의 회사다. 접점은 영업 담당자를 통해 열리며 **비용이 없다.**

**지금 놓치고 있는 것**: 이 관계를 관리하는 담당자가 없다.

**🔴 확인 필요 2건**: ① TF 건이 우리 요청이었는지 TF 제안이었는지(재현 가능성을 결정) ② **그 보도자료를 현재 우리 사이트에서 자산으로 쓰고 있는지** — 어렵게 얻은 3자 기록을 자기 채널에서 활용조차 안 하고 있을 가능성.

## 7. 레지스트리 심화

### 7-1. 무엇이 레지스트리인가 — 5종

**① 규제기관 공개 DB** (가장 강력)
FDA(화장품 MoCRA 리스팅 / 의료기기 Establishment Registration & Listing) · **UK MHRA**(KoraVie Shield Class 2a) · EU CPNP·CE·EUDAMED · 한국 MFDS 의료기기 DB · 브라질 ANVISA · 기타 등록국

**② 인증기관·인정기구 DB**
ISO 13485 / 22716 인증서는 **발급기관 고객 디렉토리** 또는 **IAF CertSearch** 등 국제 인정 검색 DB에서 조회 가능한 경우가 있음.
→ **스캔 이미지는 위조 가능하나 인증기관 DB는 불가능하다.** 실사에서 이 차이가 전부.

**③ 산업 디렉토리** — CPHI Online(닥터박 등록 확인) · CDMO/원료 디렉토리

**④ 기업·금융 DB** — D-U-N-S 넘버(조달·입찰에서 요구되는 경우) · LinkedIn 기업 페이지 · Crunchbase · 법인 등기(UK Companies House / Delaware)

**⑤ 특허·임상 DB** — KIPRIS·Espacenet·Google Patents(영구 기록) · **ClinicalTrials.gov**
> NeuroDP가 임상에 진입하면 ClinicalTrials.gov에 등재된다. **유전자치료 회사에게 이는 가장 강력한 3자 기록** — 등재 순간부터 전 세계 애널리스트·투자자·경쟁사가 데이터로 추적한다.

### 7-2. 왜 유독 강한가 — 5가지

1. **우리가 못 고친다** — 3자 유지 → 의심 불가
2. **영구적이다** — 보도자료는 뉴스 사이클이 끝나면 묻히지만 등재는 남는다
3. **🔑 검색에서 딜러를 이긴다** — 규제기관 도메인은 권위가 압도적. **정부 DB가 GANA를 언급하면 루마니아 쇼핑몰보다 위에 뜬다.** 즉 SEO 문제를 **자사 사이트 개선이 아니라 3자 기록 확보로 우회**할 수 있다. 더 빠르고 확실하다
4. **실사에서 유일하게 통과한다** — 배지 이미지 0점, 레지스트리 번호 만점
5. **이미 보유하고 있다** — 신규 투자가 아니라 **이미 지불한 등록비의 회수**. 통합보고서 §5-5: *"두 사이트 모두 인증을 주장하나 다운로드 가능한 원본 증빙이 없음"*

### 7-2b. 🔴 조사 결과 — 가설은 맞았으나 자산은 예상한 곳에 없었다 (v2)

[전수조사](source/2026-07-22_레지스트리_전수조사_결과.md)로 위 5번 가설을 검증한 결과:

| 기대했던 곳 | 결과 |
|---|---|
| FDA 의료기기 등록 | 🔴 **실질 부재** — 동일 건물 타사(AIOBIO·KYK)는 정상 등재, GANA만 0건 |
| FDA Registered(화장품) | 🔴 실제는 **VCRP 자발적 등록**. 2023-03 접수 중단, 조회 도구 부재 |
| CE | 🔴 **2024-05-27 만료** |
| MFDS GMP | 🔴 **2020-02-26 만료** |
| UK MDR Class 2a | 🔴 **Class I** (오표기) |
| ISO 13485/22716 · IAS | ⚠️ IAF CertSearch·IAS 디렉토리 **미발견** |
| ANVISA | ⚠️ 번호 미제시 + DB 접근 불가 |

| 기대하지 않았던 곳 | 결과 |
|---|---|
| **러시아 Roszdravnadzor** | 💰 **유효 등재 8건.** 공개 API 직접 조회 성공. 제조사·주소 일치, 동명이인 오염 없음. **그런데 사이트에 등록번호가 0건** |

**회수 가능한 자산은 실재한다. 다만 우리가 보던 곳이 아니라 러시아에 있었다.**

> ⚠️ **그리고 "Russia FDA"는 존재하지 않는 기관명이다.** 실제 기관은 러시아 연방보건감독청(Roszdravnadzor)이다. 현재 사이트 표기 *"Russia FDA approved"*는 실사자에게 **"이 회사는 규제 체계를 정확히 모른다"**는 신호를 준다. 같은 이유로 **"KFDA"도 2013년 폐기된 명칭**(현 MFDS)이다.
>
> **`"Russia FDA approved"` → `"러시아 Roszdravnadzor 등록 РЗН 2021/14277 외 7건"` + 조회 링크.**
> 이 한 줄 교체가 **비용 0원으로 얻는 최대 이득**이다.

### 7-3. 실행 5단계

| 단계 | 내용 | 산출물 |
|---|---|---|
| **1** | **등재 인벤토리 전수 조사** — 어느 레지스트리에 무슨 번호로 올라가 있는가. *현재 이를 아는 사람이 없을 가능성이 높음(담당자 캐비닛·개인 기억에 분산)* | 등재 대장 |
| **2** | **공개 조회 URL 확보** — 번호만으로 부족. 검색 결과 페이지 직접 링크가 있어야 3자 증거 | URL 목록 |
| **3** | **Trust Center를 배지→링크로 교체** — "우리가 주장한다" → **"규제기관이 기록한다"** | Trust Center 사양 |
| **4** | **갭 분석(양방향)** — ⓐ 주장하는데 미등재 = 🔴 즉시 정리 / ⓑ **등재됐는데 미주장 = 가장 아까운 케이스(더 많을 것)** | 갭 리스트 |
| **5** | **신규 등재 전략** — 미진출 시장 중 등재 자체가 자산이 되는 곳 + DMF 등 **자발적 등록**(의무 아닌데 하면 그 자체가 신뢰 신호) | 등재 로드맵 |

### 7-4. ⚠️ 주의 2건

- **1단계에서 나쁜 소식이 나올 수 있다.** 통합보고서는 인증 스택을 *"조합은 타당하나 독립 레지스트리 미확인 = 자사 주장 단계"*로 분류했다. 전수 조사 시 **주장했으나 확인 불가 항목**이 나올 수 있다. 불편하지만 **실사에서 발견되는 것보다 지금 발견되는 것이 압도적으로 낫다.**
- **등재 확대에는 유지 비용이 붙는다.** 갱신비·현지 대리인 지정·사후 관리 의무. 가시성만 보고 늘리면 안 되며 실제 사업 계획과 정합해야 한다.

### 7-5. 부산물

레지스트리 인벤토리를 만들면 **인증 관련 팩트시트가 자동 완성된다**(등재기관·번호·범위·유효기간·발급처 일람). 선결 과제인 **팩트시트 단일화의 절반이 이 작업으로 끝난다.**
