## 1. 🔑 가장 중요한 해석 — 조사는 전략의 반증이 아니라 검증이다

우리는 [가시성 채널 전략 §9](GANA_가시성채널_전략.md)에서 **"정리 → 노출"** 순서를 주장했다. 근거는 *"보이기 시작하면 검증도 시작된다"*였다.

**조사 결과가 그 판단이 옳았음을 증명했다.**

만약 순서를 뒤집어 가시성부터 올렸다면 지금 노출됐을 것들:
- **2020년 만료된 GMP 적합인정서**와 **2024년 만료된 CE 인증서**가 배지로 걸린 상태
- **존재하지 않는 미국 FDA 의료기기 등록**을 "FDA approved"로 표기
- KoraVie **Class I을 Class 2a**로 표기
- 생산용량 **5,000 / 6,000 / 200,000L 세 숫자 동시 노출**
- **"Russia FDA"·"KFDA"** 등 존재하지 않거나 폐기된 기관명

**이 상태로 산업 리포트에 등재 신청하거나 학회에 나갔으면 그게 사고였다.** 회장님 보고에서 이 프레임을 그대로 쓸 수 있다.

> *"보이게 해드리겠다고 말씀드렸고, 보이기 전에 숫자를 맞춰야 한다고도 말씀드렸습니다. 맞춰보니 — 맞출 게 생각보다 많았습니다."*

## 2. 🔴 전략을 흔드는 3대 발견

### 2-1. 법인 귀속 — 가장 무거움

동일 건물(둔촌대로 555 선일테크노피아)에 대표자가 다른 별도 법인이 있다.

| 법인 | 대표 | 확인 근거 |
|---|---|---|
| GANA R&D | **박용호** | 러시아 등재 8건 제조사 일치 |
| **㈜지씨에스 (GCS)** | **김창식** | 사업자등록 105-87-54103, 1008호 |

2019-12 언론 보도상 **"PLLA 필러 세계 2번째 CE 획득"과 "국내특허 28건·해외특허 12건"의 주체는 ㈜지씨에스**다.

**전략적 함의 — 이게 왜 심각한가**

우리 빅 도미노는 **"GANA는 성분을 자사 GMP로 직접 만드는 제조사다"**였다. 이 명제의 증거로 CE·특허·장비 스코프를 써왔다. **그런데 CE와 특허 40건이 다른 법인 것이라면 증거의 일부가 남의 것이다.**

- 사다리의 **뿌리 정의 자체**가 흔들린다 — 뿌리가 GANA R&D인가, 두 법인의 합인가
- 실사에서 **가장 먼저 터지는 항목**이다. 특허·인증은 실사 첫 페이지다
- **→ 등기부등본·주주명부로 관계 확정이 모든 후속 작업의 선행 조건.** 브랜드 작업보다 앞선다

**세 가지 시나리오와 각각의 대응**

| 시나리오 | 아키텍처 영향 |
|---|---|
| 두 법인이 실질 동일 지배(계열) | 뿌리를 **"GANA 제조 체계"**로 정의하고 두 법인을 그 안에 포함. 대외 표기 일원화 |
| 별개 법인이나 라이선스·협력 관계 | CE·특허를 **자사 자산으로 표기 금지.** "협력사 보유"로 정확히 |
| 무관 | 해당 실적 **전면 삭제.** 빅 도미노 증거를 장비·러시아 등재로 재구성 |

### 2-2. 성좌 축소 — 5개 법인 서사는 실체보다 컸다

[아키텍처 §2](archive/04_브랜드아키텍처_재생사다리_2026-07-22.md)에서 "박용호 성좌 3층"을 그룹 서사의 뼈대로 세웠다. **조사 결과 실체 강도가 극명하게 갈린다.**

| 법인 | 실체 근거 | 판정 |
|---|---|---|
| **GANA R&D** | 러시아 유효 등재 **8건**, 제조사명·주소 일치 | 🟢 **확인** |
| **Dr.Park CDMO** | 도메인 **2022-04 한국 인프라(Gabia)**, TF 보도자료 3자 검증, CPHI 프로필 | 🟢 **확인** |
| KoraVie | 법인 실재(#16354321). 단 **2025-03 설립 · 자본금 GBP 238 · SIC 46450 화장품 도매 · 박용호 임원/PSC 아님 · 등기주소와 사이트 주소 불일치** | 🟡 **실재하나 격하** |
| NeuroDP | 도메인 **2026-03-17 Wix, 등록자 비공개**. ClinicalTrials·SEC·LinkedIn 전부 0건 | 🔴 **보류** |
| Dr.Park Pharmaceutical | 도메인 **2026-04-15 Wix, 등록자 비공개**. 동일하게 전부 0건 | 🔴 **보류** |

**결정적 대비**: Dr.Park CDMO는 4년 3개월간 한국 인프라로 운영됐고, NeuroDP·drpgt는 **3~4개월 전 생성된 Wix 사이트**다. **두 그룹을 같은 무게로 다루면 안 된다.**

**전략적 함의**
- 그룹 서사를 **"제조–개발–상업화 3층 성좌"**로 대외 발신하면 실사에서 개발·상업화 축이 비어 있음이 드러난다
- **→ 대외는 확인된 2축(GANA R&D 제조 + Dr.Park CDMO 제조)으로만.** 나머지 3건은 확인 후 편입
- 역설적으로 이건 **우리 전략을 단순화한다** — 두 축 다 "제조"라, [시나리오 B(ODM·수탁 제조)](GANA_각사별_리브랜딩_전략.md)가 실체에 가장 부합하는 포지션이 된다

## 3. 💰 살아난 것 — 러시아 8건, 그리고 그것이 말해주는 것

조사에서 유일하게 **완전히 검증된 3자 기록**이다. 공개 API로 직접 조회했고 제조사·주소가 일치하며 동명이인 오염이 없다.

| 등록번호 | 제품 | 사다리 층 |
|---|---|---|
| РЗН 2021/14277 | GANA HA (A/B/C) | L1 |
| РЗН 2021/13973 | GANA X / V (PLLA) | L1 |
| РЗН 2022/18121 | GANA HA Body | L1 |
| РЗН 2024/22440 | GANA BOOSTER | L1 |
| РЗН 2024/22794 | GANA PH (PLLA+HA) | L1 |
| РЗН 2025/26343 | GANA Filler X (PCL+HA) | L1 |
| РЗН 2025/26344 | GANA CH (칼슘+HA) | L1 |
| **РЗН 2024/22431** | **GANA PATCH (하이드로겔 창상피복재)** | **L2** ⭐ |

**세 가지 전략적 의미**

**① 사다리 L1이 3자 기록으로 증명됐다.** HA·PLLA·PCL·칼슘 — **성분 플랫폼 다각화가 등재 목록으로 실증된다.** 빅 도미노("성분을 직접 만든다")의 가장 강한 공개 증거가 여기 있었다. 우리가 장비 스코프로 논증하던 걸 **규제기관 기록이 대신 해준다.**

**② L2가 비어 있지 않았다.** GANA PATCH가 РЗН 2024/22431로 유효 등재돼 있다. 우리는 L2를 "의도적 여백"으로 처리했는데, **여백이 아니라 등재된 실체가 있었고 다만 아무도 말하지 않고 있었다.**

**③ 그런데 사이트엔 등록번호가 0건이다.** 표기는 **"Russia FDA approved"** 한 줄뿐이고, **"Russia FDA"는 존재하지 않는 기관명**이다. 실제는 러시아 연방보건감독청(Roszdravnadzor)이다.

> **이 대비가 이 프로젝트의 진단을 완성한다.**
> **가진 것(러시아 8건)은 한 줄로 뭉개고, 없는 것(FDA·CE·Class 2a)은 배지로 크게 건다.**
> 리브랜딩의 본질은 새 언어를 만드는 게 아니라 **이 방향을 뒤집는 것**이다.

**그리고 결정적 발견**: 조사 3사 중 **누구도 AAV 단일 배치 축으로 "world's largest"를 쓰지 않는다.** Catalent는 세포치료·시설 면적 축의 "one of", Minaris는 "world-class"(품질 축). **[포지셔닝 분석 §1-1](GANA_world-largest_포지셔닝_분석.md)에서 세운 "단일 배치 축은 빈 축"이라는 판단이 재확인됐다.**

**🔴 그런데 쓸 수 없는 이유가 남았다 — 우리 숫자가 셋이다**

| 출처 | 수치 |
|---|---|
| Thermo Fisher 공식 보도자료 | **5,000L**/batch, 연 40배치 |
| drpark-cdmo.com | **6,000L**/batch |
| CPHI Online | **6,000L**/batch |
| koravie.info | **200,000L** |

**200,000L는 자사 공식 보도자료의 40배다.** 실사자가 보도자료와 웹사이트를 나란히 놓는 순간 발견된다.

> **권고**: 절대 최상급 격상 보류. 현 시점 사용 가능 문구는
> **"업계 공개 자료 기준 최대 수준(2,000L)을 상회하는 5,000L 단일 배치"**
> 그리고 **용량 수치 단일화가 이 문구의 선결 조건**이다 — 이건 [포지셔닝 분석 §0](GANA_world-largest_포지셔닝_분석.md)에서 이미 세운 원칙이고, 조사가 그 필요성을 실증했다.

**추가 과제**: 자사 5,000L가 **실가동 cGMP 실적인지 설계 규격인지** 먼저 확정해야 공정한 비교가 된다. 경쟁사 수치 다수가 설계 스펙이다(Minaris는 실증 200L/설계 2,000L를 명시 구분).

```
   L3 ── 세포·유전자 재생
   개발   NeuroDP · Dr.Park Pharma          🔴 보류 (도메인 3~4개월, 근거 0)
   제조   Dr.Park CDMO                      🟢 확인 (2022~, TF 보도자료)
             ▲
   L2 ── 조직 재생
   제품   GANA PATCH  РЗН 2024/22431        🟢 확인 ⭐ 여백 아니었음
   상업화  KoraVie Shield                    🔴 Class I (2a 아님)
             ▲
   L1 ── 피부 재생
   제품   HA·PLLA·PCL·칼슘 계열              🟢 확인 (러시아 등재 7건)
   제조   GANA R&D                          🟢 확인
             ▲
  ═══ 뿌리 ── GANA R&D ═══                  ⚠️ 법인 귀속 확정 필요 (㈜지씨에스)
```

**판정: 사다리는 유지된다. 오히려 L1·L2는 조사 전보다 근거가 강해졌다.**

수정 사항 3건:
1. **L2를 "의도적 여백"에서 "저평가된 실체"로 재분류** — GANA PATCH가 등재돼 있었다
2. **L3 개발 축 보류** — 확인 전까지 대외 서사·홍보물 등장 금지
3. **상업화 축 재정의** — KoraVie는 자본금 GBP 238 신설 법인이다. "글로벌 상업화 축"으로 세우기엔 실체가 부족하다. **L1 자사 딜러망을 상업화 주력으로 재배치**하는 것이 실체에 부합
