## 0. 한 장 요약

기획서의 진단·전략·실행 순서는 옳다. 그러나 **마스터 문구 한 줄과 규모 문구 한 줄이 현재 근거로는 지켜지지 않는다.**

| 구분 | 판정 | 조치 |
|---|---|---|
| 축 전환 논리(약속 → 사실) | 🟢 유지 | 없음 |
| "정리 → 노출" 순서 | 🟢 유지 | 없음 |
| 증거 체계(러시아 8건) | 🟢 유지 · 강화 | 62건 전체로 확대 |
| **마스터 슬로건 "표면부터 세포까지 직접 만든다"** | 🔴 **현 근거로 방어 불가** | **§1 시제 분리** |
| **"5,000L 단일 배치" (7.2 권장 문구)** | 🔴 **기획서가 안전하다고 본 문구가 안전하지 않다** | **§2 재작성** |
| 리스크 R1·R2의 지위 | 🔴 각주 → 게이트로 승격 | §3 |
| 리스크 등록부 누락 3건 | 🔴 추가 | §4 |
| KPI 검증 가능성 | ⚠️ 베이스라인 없음 | §5 |

> **핵심 한 줄**: 기획서는 "약속을 그만두고 만든 것을 보여주자"고 한다. 그런데 **마스터 문구 자체가 아직 약속이다.** 깊이 3은 "만들었다"가 아니라 "지었다"까지가 사실이다.

## 1. 🔴 최우선 — 마스터 슬로건의 시제(時制) 분리

### 1-1. 무엇이 문제인가

기획서 마스터: **"표면부터 세포까지, 재생을 직접 만듭니다"**

이 문장은 **하나의 주어(우리)가 양 끝단을 모두 만든다**고 읽힌다. 그런데 조사 결과 양 끝단의 상태가 완전히 다르다.

| | 깊이 1·2 (표면·조직) | 깊이 3 (세포·유전자) |
|---|---|---|
| 주체 | (주)가나알엔디 | (주)닥터박 |
| GMP | 🟢 **MFDS 의료기기 GMP 현행** `KCL-ABBA-19926` (~2027-03-03) | 🔴 **cGMP 미취득.** 사이트 원문 *"we aim to achieve"* |
| 제조 실적 | 🟢 품목허가 27건 · 러시아 8건 · MHRA Class III · ANVISA 2건 | 🔴 **cGMP 배치 실행 실적 0건** |
| 특허 | 🟢 등록 2건 (단, 박용호 개인 명의) | 🔴 **AAV·유전자치료 특허 0건** |
| 논문 | — | 🔴 **PubMed 0건** |
| 임상 | — | 🔴 **ClinicalTrials 전 항목 0건** |
| 시설 | 8·10F | 12F, Phase 1 **2025-08-05 준공** (11개월 경과) |

그리고 **두 축을 잇는 근거가 문서상 0건이다.**

- 기술 연속성 — 근거 0건
- 설비 연속성 — 오히려 **250L SUB·50L SUB·AKTA PILOT 600이 양쪽 사이트에 중복 게시**되어 있어 귀속 미확정 상태
- 인력 연속성 — **박용호 1인 외 0건.** 그마저 공개 등기상 어느 법인의 대표자도 아니다 (가나알엔디 대표 = 김진홍)
- 자본 관계 — **지분·출자 서술 6사 중 1건(닥터박 "외부투자 없음")뿐**

> **결론**: "직접 만든다"의 **표면 절반은 규제기관 문서로 증명되고, 세포 절반은 아직 증명되지 않는다.** 현 문장은 증명된 절반의 신뢰를 미증명 절반에 빌려주는 구조이며, 실사에서 **증명된 쪽까지 함께 의심받는다.**

### 1-2. 해법 — 시제를 나눈다

부정하지 않고, **완료형과 진행형을 구분**한다.

```
  마스터   표면부터 세포까지, 우리는 만드는 쪽에 있습니다
           We are on the making side — from the surface to the cell.

  깊이 1·2  완료형  "만들었습니다"      → 등재번호로 증명
  깊이 3    진행형  "짓고 있습니다"      → 준공일·장비명으로 증명
```

| 층 | 대외 문장 | 붙이는 증거 |
|---|---|---|
| **깊이 1** | "성분부터 만들었습니다" | РЗН 8건 · MFDS 품목허가 27건 · MHRA Class III · ANVISA 2건 · GMP `KCL-ABBA-19926` |
| **깊이 2** | "조직에 쓰는 것도 이미 등재돼 있습니다" | РЗН 2024/22431 (GANA PATCH) · MFDS 제인20-4997 |
| **깊이 3** | "세포 단위 제조 시설을 **지었습니다.** cGMP는 2026년 목표입니다" | 2025-08-05 준공 · Thermo Fisher 공동 릴리스 · 장비 실명 |

**왜 이게 더 강한가**

1. **실사에서 무너지지 않는다.** 실사자가 12층에 올라가서 "cGMP 인증서 주십시오"라고 했을 때 *"2026년 목표라고 사이트에 적어뒀습니다"* 는 정상이다. *"세포까지 직접 만듭니다"* 라고 해놓고 인증서가 없으면 그때부터 **1층 필러의 러시아 등재 8건까지 의심받는다.**
2. **R1이 거짓이어도 문장이 산다.** 두 축을 하나의 생산라인으로 잇지 않으므로, 등기 확인 결과가 어떻게 나오든 문구를 다시 쓸 필요가 없다.
3. **IR 서사로는 오히려 유리하다.** "다 갖췄다"보다 "1층은 팔고 있고 3층은 짓고 있다"가 투자 스토리다. 완성된 회사에는 투자할 이유가 없다.

### 1-3. 사용 주의 (기획서 6.1 갱신)

| 표현 | 등급 | 사유 |
|---|---|---|
| "표면부터 세포까지 **직접 만듭니다**" (현재형·완료 함의) | 🔴 **G1 통과 전 금지** | 깊이 3 cGMP 미취득 |
| "표면부터 세포까지 **만드는 쪽에 있습니다**" | 🟢 사용 가능 | 사실 진술 |
| "GANA **그룹**이 만듭니다" (그룹 단일 주어) | 🔴 **금지** | 6사 자본관계 미확인. 전수분석 카피 금지 목록과 동일 |
| 각 사 명의의 "우리가 만들었습니다" | 🟢 사용 가능 | 법인별 증거 존재 |

## 2. 🔴 "5,000L 단일 배치" — 기획서가 안전하다고 본 문구가 안전하지 않다

기획서 7.2는 최상급을 포기하고 다음을 "현 시점 사용 가능 문구"로 제시한다.

> *"업계 공개 자료 기준 최대 수준(2,000L)을 상회하는 **5,000L 단일 배치**"*

**이 문구도 아직 쓸 수 없다.** 이유가 셋이다.

| # | 문제 | 근거 |
|---|---|---|
| 1 | **"단일 배치"가 사실이 아닐 수 있다.** 자사 게시 장비 목록은 **HyPerforma 1,000L SUB × 5기 + 500 + 250 + 50 = 5,800L 합산**이다. 5,000L 단일 반응기는 목록에 없다 | 자사 사이트 장비 목록 |
| 2 | **Thermo Fisher 실제 납품 장비도 1,000L SUB**다. 공동 릴리스의 5,000L는 시설 설계 스펙이지 반응기 규격이 아니다 | TF 공동 릴리스 (BusinessWire 20250923771397) |
| 3 | **cGMP 미취득 = cGMP 배치 실적 0.** working volume·수율·배치기록 어느 것도 문서에 없다 | 조사 §6-6 |

업계 대조가 이 위험을 확정한다. **Forge의 5,000L도 원문이 "1L~500L 실측에서 외삽(extrapolated)"**이고, **Minaris는 실증 200L / 설계 2,000L를 명시 구분**한다. 즉 **경쟁사들은 이미 "설계"와 "실증"을 나눠 쓰고 있다.** 우리만 나누지 않으면 그 자체가 신호가 된다.

### 해법 — 반응기가 아니라 시설로 말한다

| 등급 | 문구 |
|---|---|
| 🔴 금지 | "World largest AAV vector CDMO" · "세계 최대 AAV 생산능력" · "200,000L" |
| 🔴 **신규 금지** | "5,000L **단일 배치**" — 단일 반응기 여부 미확정 |
| 🟢 **권장 (현 시점)** | **"AAV 생산 설계 용량 5,000L 규모의 Phase 1 시설 (2025년 8월 준공, cGMP 2026년 목표)"** |
| 🟢 보조 | "업계 공개 자료 기준 단일 배치 최대 수준은 2,000L다" — **경쟁사 수치만 제시하고 비교는 독자에게 맡긴다** |
| 🎯 향후 | cGMP 취득 + 실배치 기록 확보 이후 → "5,000L 배치 실적" 사용 가능 |

> 기획서 7.3의 논리("규모에 목적을 붙인다")는 그대로 살아있다. 바꾸는 것은 **숫자의 성격 표기**뿐이다.
> *"자랑하려고 크게 지은 것이 아닙니다. 세포 단위까지 만들려니 이 규모가 필요했습니다"* → **"지은 것"**이 주어이므로 이 문장은 지금도 참이다.

## 3. 🔴 게이트 구조 — 리스크 각주를 승인 조건으로 승격

기획서는 승인 요청 3건(12장)을 앞에, 미확인 리스크 R1·R2를 뒤(11장)에 둔다. **결재자가 이 순서대로 읽으면 미확인 위에 승인이 얹힌다.** 순서를 뒤집는다.

```
  G0 ─────────► G1 ─────────► G2
  응급 정리      축 확정        규모·확장 발화
  (즉시)        (등기 확인 후)   (cGMP 취득 후)
```

### G0 — 즉시 착수 (승인 불요 · 비용 0원)

**아무 확인 없이도 지금 해야 하는 것.** 전부 "틀린 것을 지우는" 작업이라 확인 대기 이유가 없다.

| # | 조치 |
|---|---|
| 1 | 만료 인증 배지 내림 — CE(~2024-05-27) · KGMP 만료본(~2020-02-26) · ISO 13485(~2016) · ISO 9001(~2018) |
| 2 | "Russia FDA" → **Roszdravnadzor РЗН 8건 + 조회 링크** |
| 3 | "FDA approved"(의료기기) 삭제 — 실질 부재 확정 |
| 4 | "FDA Registered"(화장품) → VCRP 자발 등록 명시 또는 삭제. **VCRP는 FDA가 광고 사용을 명시 금지** |
| 5 | KoraVie "Class 2a" → **Class I** |
| 6 | **koravie.info 수치 4종 삭제** — 200,000L · 70억 도즈 · +400% · +156% |
| 7 | ganarnd.co.kr SSL 교체 · 도메인 이메일 전환 |
| 8 | 표기 정정 — KFDA→**MFDS** · 순일→**선일**테크노피아 · 우편번호 **13215** |
| 9 | GMP 현행본 게시 — **`KCL-ABBA-19926`(~2027-03-03)**. 가진 것을 안 쓰고 있다 |
| 10 | 🚨 **만료 임박 2건 즉시 대응** — EUDAMED 인증대리인 위임 **2026-07-25 만료(D-2)** · ANVISA GANA X **2026-08-19 만료** |

### G1 — 축 확정 게이트 (승인 요청 1·2의 선행 조건)

**아래 4건이 전부 닫히기 전에는 새 슬로건을 대외 발화하지 않는다.**

| # | 확인 항목 | 방법 | 통과 기준 |
|---|---|---|---|
| **G1-1** | **㈜지씨에스(105-87-54103, 대표 김창식) ↔ 가나알엔디(107-88-12144, 대표 김진홍) ↔ 박용호 3자 관계** | 법인등기부등본 · 주주명부 | 세 가지 중 하나로 확정: 실질동일지배 / 라이선스 / 무관 |
| **G1-2** | **CE·특허 40건의 귀속 법인** | 2019-12 보도 원문 대조 · US11400182B2 양수인 확인 | GANA 자산인지 GCS 자산인지 확정 |
| **G1-3** | **설비 자산 법인별 귀속** — 250L SUB · 50L SUB · AKTA PILOT 600 · CAR-T 장비 · 동물시험센터 | 자산대장 | 중복 게시 해소. 그룹 총 용량 과대계상 제거 |
| **G1-4** | **가나알엔디 본점 소재지 정본** | 등기부 | 국세청 등록 본점이 **원주**인데 전 대외자료가 성남이다. "본점 원주 / 제조소 성남" 표기로 통일 |

> **G1-1이 왜 R1보다 먼저인가**: 기획서 R7이 "동일 건물 별도 법인"으로 다루는 항목이 실제로는 **CE 인증 1건과 특허 40건의 소유권 문제**다. 이것이 남의 것이면 "직접 만든다"의 **증거 절반이 남의 것**이 된다. 실사 첫 페이지에서 터지는 항목이며, 브랜드 작업 전체보다 앞선다.

### G2 — 규모·확장 발화 게이트

| # | 확인 항목 | 통과 기준 |
|---|---|---|
| G2-1 | Dr.Park CDMO **cGMP 취득** | 인증서 원본 |
| G2-2 | 5,000L의 성격 확정 | ① 명목 용량 ② working volume ③ cGMP 배치 실적 — 세 가지를 구분해 기재 |

**G2 통과 전까지 "10,000L"는 어떤 문서에도 등장 금지.** 원문이 *"if there is a client's request"* 인 조건부 진술이며, TF 릴리스도 *"in the future"* 다.

## 4. 리스크 등록부 추가 3건

기획서 11장에 다음을 추가한다.

| # | 리스크 | 상태 | 영향과 대응 |
|---|---|---|---|

## 6. 승인 요청 재구성

기획서 12장을 다음으로 대체한다. **요청 건수는 3건 그대로이나 순서와 조건이 바뀐다.**

### 요청 1 — 즉시 정리 착수 승인 (G0)

비용 0원, 10개 항목, 1주. **전부 틀린 표기를 지우는 작업이므로 다른 어떤 결정도 기다리지 않는다.**
이 중 2건(EUDAMED 위임 만료 D-2, ANVISA 갱신)은 **브랜드가 아니라 판매 자격의 문제**이며 지연 시 등재가 끊긴다.

### 요청 2 — 법인·자산 귀속 확인 착수 승인 (G1)

법무 주관. 등기부등본·주주명부·자산대장 4건.
**브랜드 예산이 아니라 실사 대응 예산이다.** 이것이 닫히기 전 새 슬로건은 발화하지 않는다.

### 요청 3 — 축 전환 승인 (조건부)

**G1 통과를 조건으로** 대외 축을 "재생을 직접 만든다"로 전환한다.
단 마스터 문구는 §1-2의 **시제 분리형**을 채택하고, 규모 문구는 §2의 **설계 용량 표기형**을 채택한다.

## 7. 회장님 보고 프레이밍 — 한 줄 추가

기존 프레이밍(*"가진 것은 안 쓰고, 없는 것은 크게 걸고 있습니다"*)은 그대로 유지하되, 게이트를 설명할 한 줄이 필요하다.

> **"이번 전환의 유일한 위험은, 우리가 '만든다'고 말하는 순간 상대가 '보여달라'고 한다는 것입니다.
> 1층은 지금 당장 보여드릴 수 있습니다 — 등록번호가 여덟 개 있습니다.
> 3층은 건물은 보여드릴 수 있지만 인증서는 내년입니다.
> 그래서 1층은 '만들었습니다', 3층은 '짓고 있습니다'로 나눠 말하려 합니다.
> 나눠 말하면 둘 다 사실이고, 붙여 말하면 둘 다 의심받습니다."**
