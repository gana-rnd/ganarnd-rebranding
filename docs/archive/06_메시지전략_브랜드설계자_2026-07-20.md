# GANA 그룹 메시지 전략 — 《브랜드 설계자》 프레임 적용

- **작성 기준일**: 2026-07-20
- **베이스**: [통합보고서 v2.1](../GANA_그룹_리브랜딩_통합보고서_v2.md) · 검증된 팩트만 사용(신뢰도 표기 §통합보고서 규칙 준용)
- **출처 프레임**: 러셀 브런슨 《브랜드 설계자》(*Expert Secrets*)
- **적용 원칙**: 이 책은 본래 **개인 브랜드·인포마케팅 퍼널**용이다. 여기서는 **메시지 설계의 뼈대만** 차용하고(포지셔닝 프레임·메시지 위계·반론 설계), **화법·톤은 전량 폐기**한다. GANA는 6개국어로 **해외 규제기관·바이어·CDMO 파트너**가 보는 B2B 사이트이므로, 직접반응(direct-response)식 과장 화법은 오히려 신뢰를 깎는다.

## 0. 한 장 요약

| 책의 개념 | 원래 의미 | GANA 적용(무엇을) | 톤 조정(어떻게) |
|---|---|---|---|
| New Opportunity | "개선"이 아닌 "새로운 기회"를 팔라 | "더 좋은 필러사"(개선) → **"성분을 직접 만드는 제조 플랫폼 그룹"**(기회) | 선언 대신 **장비·인증·실적으로 증명** |
| Big Domino | 하나만 믿게 하면 나머지가 따라온다 | **"GANA는 성분을 자사 GMP로 직접 만드는 제조사다"** | 슬로건 아님 — 최상단 신뢰 앵커 |
| Epiphany Bridge | 연혁 나열 대신 전환의 서사 | "왜 필러사가 유전자치료로 갔는가" | 감정 호소 X, **사실 기반 진화 서사** |

## 1. New Opportunity — 포지셔닝 프레임 전환

브런슨의 제1원칙: **사람은 "지금 것의 개선"보다 "완전히 새로운 기회"에 반응한다.** 개선 프레임은 기존 대안과 직접 비교당하고(=가격·스펙 경쟁), 새로운 기회 프레임은 비교 자체를 벗어난다.

- **개선 프레임(피해야 할 것)**: "더 좋은 HA 필러", "가성비 좋은 한국 필러 제조사" → 수백 개 아시아 필러 OEM과 같은 링에 선다.
- **새로운 기회 프레임(가져갈 것)**: **"HA·PLLA·PCL·PDRN·Peptide를 자사 GMP로 직접 만드는 성분 플랫폼 그룹, 그리고 그 위에 선 유전자·세포치료 제조(Dr.Park CDMO)"**.

이 전환이 정당한 이유(=자사주장이 아니라 실체):
- R&D 센터에 유전자·세포치료급 장비 실재 — Thermo Fisher 바이오리액터·Sanger 시퀀서·Beckman 셀소터·AKTA FPLC·CAR-T 장비(CTS Rotea)·생물정보 서버(40CPU/256GB/200TB). (확인, 통합 §2-3)
- Dr.Park cGMP 바이러스 벡터 시설 + Thermo Fisher 장비 도입. (확인, 통합 §2-2)
- 동일 창업자(박용호)·동일 주소로 묶이는 제조–개발–상업화 3층 성좌. (확인, 통합 §2-2b)

> **적용 지점**: 히어로 헤드라인, About, 그룹 소개. "필러"라는 단어를 카테고리 라벨로만 쓰고, **정체성 단어는 "제조 플랫폼 / manufacturer"**로.

## 2. Big Domino — 메시지 위계(증거 구조)

브런슨: **모든 세일즈는 하나의 핵심 신념(빅 도미노)으로 환원된다.** 그 하나를 믿게 만들면 나머지 반론이 도미노처럼 무너진다. B2B에서 이 "믿음"은 감정이 아니라 **입증 가능한 사실**이어야 한다.

### GANA의 빅 도미노 후보 (우선순위)

**1순위 도미노 — "GANA는 성분을 자사 GMP로 직접 만드는 제조사다."**
- 이걸 믿으면 → 품질 통제·COA·ODM·규모·가격 협상력이 전부 따라온다.
- 증거: 자동 바이알 충전 라인(20,000 vials/hr)·동결건조실·R&D 4대 분야 장비 스코프. (확인)

**2순위 도미노(신뢰 정점) — "글로벌 표준 바이오프로세싱으로 구축한 cGMP 시설을 그룹이 보유한다."**
- Thermo Fisher 장비로 구축한 Dr.Park AAV 벡터 시설. (확인)
- ⚠️ **정직 프레이밍 필수**: TF 건은 **"장비 구매/선정"**이지 투자·합작·품질보증·"파트너십/인증"이 아니다. 오도하면 실사에서 역효과. 카피는 **"글로벌 표준 장비로 구축한 cGMP 시설"** 수준으로.

### 메시지 위계 (홈 랜딩에 그대로 매핑)

```
[빅 도미노]  성분을 직접 만드는 제조 플랫폼 그룹이다
      │
      ├─ 증거층 A (제조 역량)
      │   · 자사 GMP 공장 — 자동 충전 20,000/hr, 동결건조실
      │   · 성분 플랫폼 4트랙: HA · Biostimulator(PLLA/PCL/CaHA) · PDRN/PN · Peptide/Thread
      │
      ├─ 증거층 B (규제 신뢰)
      │   · 배지 라인: CE · MFDS · ISO 13485 · ISO 22716 · FDA Registered(범위 각주) · ANVISA
      │   · Trust Center — 레지스트리 링크 + PDF 실물 증빙(주장→증거)
      │
      ├─ 증거층 C (R&D 깊이 = New Opportunity 근거)
      │   · R&D 센터 투어: 유전자·세포치료급 장비 실재
      │   · Dr.Park cGMP 벡터 시설(글로벌 표준 장비로 구축) — 정직 프레이밍
      │
      └─ 증거층 D (글로벌 실증)
          · 박용호 성좌: 제조(Dr.Park)–개발(NeuroDP/drpgt)–상업화(KoraVie)
          · KoraVie Shield = GANA PATCH 계열(UK MDR Class 2a) → "GANA가 만들고 KoraVie가 판다" 실증 체인
```

> 통합보고서 §7-2 홈 섹션 순서(Hero → Group bar → Product platforms → Why GANA → Proof/Trust → Dr.Park → Partnership → Inquiry)가 이 위계와 이미 정렬된다. **위 도미노는 그 순서에 "왜 그 순서인가"의 논리를 제공한다.**

## 3. Epiphany Bridge — 서사 구조(About / History)

브런슨: 청중은 **정보**가 아니라 **전환의 순간(에피파니)**을 통해 설득된다. 연혁을 "2013 설립 → 2020 …" 연도로 나열하지 말고, **"왜"의 서사**로.

GANA용 에피파니 브리지 (사실 기반, 감정 호소 배제):

1. **출발**: 필러·메조·화장품 제조로 시작(GANA R&D / Cosmetic).
2. **긴장**: 성분을 직접 만들며 쌓은 GMP·분석 역량이 미용을 넘어선다는 자각 — R&D 센터에 유전자·세포치료급 장비가 축적됨.
3. **전환**: 그 역량을 유전자·세포치료 제조로 확장(Dr.Park CDMO), Thermo Fisher 표준 장비로 cGMP 벡터 시설 구축.
4. **현재**: 제조–신약개발(NeuroDP/drpgt)–글로벌 상업화(KoraVie)의 3층 성좌.

> **적용 지점**: COMPANY > About·History(신규). 연혁 타임라인은 이 4막의 **증거 각주**로 배치.
> **주의**: "매력적인 캐릭터"·개인 영웅 서사로 흐르지 말 것. 주어는 사람이 아니라 **역량과 시설**.

## 4. False Belief — 바이어 반론 깨기(페이지 설계 체크리스트)

브런슨: 판매의 실체는 **잘못된 믿음(false belief)을 하나씩 제거**하는 것. B2B에선 이것이 **바이어·파트너의 의심 목록**이며, 각 의심마다 **증거를 붙인 페이지 요소**로 응답한다.

| 바이어의 의심(False Belief) | 응답 증거 | 사이트 배치 |
|---|---|---|
| "한국 중소 제조사인데 품질·규제가 되나?" | CE·MFDS·ISO 13485/22716·ANVISA + **레지스트리 링크·PDF 실물** | Trust/Certification Center (통합 §8-2) |
| "실제로 자기가 만드나, 아니면 재판매인가?" | 자사 GMP 공장 투어(자동 충전 라인)·R&D 장비 스코프 | Why GANA / Factory Tour |
| "필러 회사가 유전자치료를 말하는 게 과장 아닌가?" | Dr.Park cGMP 벡터 시설·TF 장비(장비 계약으로 **정직 표기**) | Dr.Park 섹션 (정직 프레이밍) |
| "그룹이라는데 실체가 있나?" | 동일 창업자·동일 주소·성좌 크로스링크·KoraVie↔GANA PATCH 체인 | Group bar / 성좌 링크 |
| "숫자를 믿을 수 있나?" | **그룹 공통 팩트시트 1벌**(배치·완공·인증 목표 통일) | 전 사이트 참조 소스 (통합 §8-4) |
| "인증이 승인인 척하는 것 아닌가?" | "FDA Registered" 범위 각주·"등록≠승인" 파트너 가이드 | 배지 각주 (통합 §9) |

> **주의**: 코스메틱의 **Rejuran 직접 비교 문구는 제거**(표시광고법·EU 비교광고 리스크, 통합 §3-2·§9). "경쟁사 깎기"로 신념을 흔드는 브런슨식 화법은 B2B에서 법적·신뢰 리스크로 직결된다. **비교가 아니라 증거로** 반론을 깬다.

## 5. 폐기 목록 — 책에서 가져오지 않는 것

B2B 바이오/의료기기 사이트에 부적합하여 **명시적으로 배제**:

- ❌ **매력적인 캐릭터(Attractive Character)** — 개인 영웅 서사. 규제기관·바이어에게 가볍게 읽힘. (§3 주의 참조)
- ❌ **무브먼트·컬트 만들기** — 신념 공동체 화법. 제조 신뢰와 무관.
- ❌ **웨비나/직접반응 세일즈 화법** — "지금 아니면 놓친다", 긴급성·희소성 압박. B2B 조달 사이클과 충돌.
- ❌ **경쟁사 직접 비교로 신념 흔들기** — 법적 리스크(§4 주의).
- ❌ **과대표현** — "World largest"·"200,000L"·"70억 도즈"·"+400%"는 근거 확보 전 완화(통합 §9). 브런슨식 "빅 프로미스"를 검증 없이 쓰면 실사에서 파산.

> **원칙 재확인**: **뼈대는 가져오되(포지셔닝 프레임·메시지 위계·반론 설계), 화법과 톤은 버린다.**
